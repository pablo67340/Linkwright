Linkwright

Your pack won't start because one mod wants version 1.3 of another, and you have 1.2? Linkwright fixes that.

Many mods only accept one exact version range of another mod, or of NeoForge, Forge or Fabric Loader itself. When that updates, the game refuses to start, even if nothing important changed.

Linkwright checks whether the two mods still fit together. If they do, it lets the game start. If something small changed, it adapts it while the game loads.

It never edits any mod files. On Forge and NeoForge you just drop it in. Fabric needs one extra step, explained below.

Works on Forge, NeoForge and Fabric, from Minecraft 1.7.10 to 26.x.

How It Works

Every time the game starts, Linkwright:

  1. Finds version rules that aren't met, between mods or on the loader.
  2. Checks every class, method and field one mod uses from the other, including mixins.
  3. Adapts small changes, but only when there is exactly one safe way to do it.
  4. Lets the game start if everything checks out. If not, you get the normal error, plus a report explaining what is missing.

A pack with 300+ mods is checked in about one second.

What It Can Fix

  • Loader version locks: a mod only accepts an older NeoForge, Forge or Fabric Loader than yours. Linkwright checks everything the mod uses in the loader, and lets it run on your newer one.
  • New parameters: a method gained extra inputs. Linkwright fills them in using values the mod already has.
  • Changed types: a value changed type, like a number becoming a bigger number type. Linkwright converts it, as long as nothing is lost.
  • Interface changes: a required method changed its types. Linkwright adds the new version and points it at the old one.
  • New return values: a method now returns something extra. Linkwright ignores it.

What It Warns About

Some problems can't be fixed, but Linkwright points them out in your log and in the report, so you know what to change:

  • Wrong Java version: a mod built for a newer Java than the one your game runs on.
  • Duplicate mods: the same mod in your mods folder twice, usually an old version left behind after an update.

Real Examples

  • CBC Aeronautics Missiles + Create: Radars 5: Radars added a new parameter to one method. Linkwright checked the other 124 links and fixed both calls.
  • Power Grid + TFMG 1.2: TFMG changed how block positions are stored. Linkwright converts them in both directions.

Safe by Design

  • It never guesses. If there is more than one possible fix, or none, it leaves the error in place.
  • It respects mod authors. If a mod is marked as incompatible with another on purpose, Linkwright leaves it alone.
  • It never loses data. Values are only converted when nothing can be lost.
  • It tells you everything. Every decision is written to logs/linkwright-report.txt.

Which File to Download

  • Forge 1.17.1 and newer, or any NeoForge: linkwright-1.2.0.jar
  • Forge 1.13.2 to 1.16.5: linkwright-1.13-1.16.5-1.2.0.jar
  • Forge 1.7.10 to 1.12.2: linkwright-1.7.10-1.12.2-1.2.0.jar
  • Fabric, any version: linkwright-fabric-1.2.0.jar

The CurseForge app picks the right one for you.

Installing

Put the jar in your mods folder. It works on the client, the server, or both. It doesn't need to match between client and server.

Linkwright starts before other mods, so on some versions it won't show up in the in-game mod list. That is normal.

Note: your client and the server still need the same versions of your other mods to connect.

Fabric: One Extra Step

Fabric checks mod versions before any mod gets to run, so Linkwright has to start a little earlier. You do this by adding one Java argument, once.

Add this argument:

-javaagent:mods/linkwright-fabric-1.2.0.jar

If your file has a different version number, change the name to match. If it doesn't work, use the full path to the file instead, and avoid spaces in the path if you can.

  • Prism Launcher or MultiMC: Edit Instance, then Settings, then the Java tab. Tick "JVM arguments" and add it there.
  • Minecraft Launcher: Installations, then Edit, then More Options. Add it to the start of JVM Arguments.
  • Other launchers: look for "JVM arguments" or "Java arguments" in the profile settings.
  • Servers: add it to your start command before -jar, for example java -javaagent:mods/linkwright-fabric-1.2.0.jar -Xmx4G -jar fabric-server-launch.jar nogui

To check it worked, look for lines starting with "Linkwright" in your log. If you see "Linkwright is installed but not active", the argument is missing or the file name doesn't match. The message shows the exact argument to use.

Settings

A settings file is created at config/linkwright.toml. The defaults work for almost everyone.

  • mode: "auto" fixes and approves (default), "report" only writes the report, "off" does nothing.
  • bridgeCalls: set to false to only approve mods that match exactly, with no fixes.
  • ignore: mod pairs to leave alone, written as "modA->modB" or "modA->neoforge".
  • forceApprove: mod pairs to allow even when problems are found. This can crash your game.

Limits

  • It checks that mods fit together, not what the code does. A method that works differently but looks the same will still pass.
  • Removed methods and renamed classes can't be fixed.
  • If a mod needs a newer loader than yours, Linkwright leaves it alone. Update your loader instead.

Requirements

  • Forge for Minecraft 1.7.10 to 26.x
  • NeoForge, any version
  • Fabric Loader 0.14 or newer, for Minecraft 1.14 to 26.x
  • No other mods needed

Quilt is not supported yet.
