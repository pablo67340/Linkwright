Linkwright

Your pack won't start because one mod wants version 1.3 of another, and you have 1.2? Linkwright fixes that.

Many mods only accept one exact version range of another mod. When that mod updates, the game refuses to start, even if nothing important changed.

Linkwright checks whether the two mods still fit together. If they do, it lets the game start. If something small changed, it adapts it while the game loads.

It never edits any mod files. No setup needed. Just drop it in.

How It Works

Every time the game starts, Linkwright:

  1. Finds mod version rules that aren't met.
  2. Checks every class, method and field one mod uses from the other, including mixins.
  3. Adapts small changes, but only when there is exactly one safe way to do it.
  4. Lets the game start if everything checks out. If not, you get the normal error, plus a report explaining what is missing.

A pack with 300+ mods is checked in about one second.

What It Can Fix

  • New parameters: a method gained extra inputs. Linkwright fills them in using values the mod already has.
  • Changed types: a value changed type, like a number becoming a bigger number type. Linkwright converts it, as long as nothing is lost.
  • Interface changes: a required method changed its types. Linkwright adds the new version and points it at the old one.
  • New return values: a method now returns something extra. Linkwright ignores it.

Real Examples

  • CBC Aeronautics Missiles + Create: Radars 5: Radars added a new parameter to one method. Linkwright checked the other 124 links and fixed both calls.
  • Power Grid + TFMG 1.2: TFMG changed how block positions are stored. Linkwright converts them in both directions.

Safe by Design

  • It never guesses. If there is more than one possible fix, or none, it leaves the error in place.
  • It respects mod authors. If a mod is marked as incompatible with another on purpose, Linkwright leaves it alone.
  • It never loses data. Values are only converted when nothing can be lost.
  • It tells you everything. Every decision is written to logs/linkwright-report.txt.

Installing

Put the jar in your mods folder. It works on the client, the server, or both.

Linkwright loads before other mods, so it won't show up in the in-game mod list. It doesn't need to match between client and server.

Note: your client and the server still need the same versions of your other mods to connect.

Settings

A settings file is created at config/linkwright.toml. The defaults work for almost everyone.

  • mode: "auto" fixes and approves (default), "report" only writes the report, "off" does nothing.
  • bridgeCalls: set to false to only approve mods that match exactly, with no fixes.
  • ignore: mod pairs to leave alone, written as "modA->modB".
  • forceApprove: mod pairs to allow even when problems are found. This can crash your game.

Limits

  • It checks that mods fit together, not what the code does. A method that works differently but looks the same will still pass.
  • Removed methods and renamed classes can't be fixed.

Requirements

  • Minecraft 1.21.1
  • NeoForge 21.1
  • No other mods needed
