Linkwright 1.3.1

New: Mods That Ask for a Slightly Newer Loader

  • Many mods ask for the exact loader build they were made with as the minimum, so a mod made on NeoForge 21.1.266 refuses to load on 21.1.265 even when nothing it uses changed.
  • Linkwright now checks these too. When your loader differs from the version the mod asks for only in the last number, it checks every class, method, field and mixin target the mod uses in the loader, and lets the mod load if all of them are there.
  • Works the same on NeoForge, Forge and Fabric Loader, for example Fabric Loader 0.16.9 when a mod asks for 0.16.10.

Safe by Design

  • If the mod uses anything that only exists in the newer build, Linkwright leaves the error in place.
  • A mod that needs a newer release of your loader, such as NeoForge 21.2 when you have 21.1, is still left alone. Update your loader for those.

New Setting

  • olderLoaderBuilds in config/linkwright.toml: set it to false to turn this off.

Fabric Users

  • The Java argument uses the new file name: -javaagent:mods/linkwright-fabric-1.3.1.jar
