Linkwright 1.2.0

New: Loader Version Locks

  • Some mods only accept one exact NeoForge, Forge or Fabric Loader version, often by accident. Linkwright now checks everything such a mod uses in the loader, and lets it run on your newer loader when it all still fits.
  • A mod that needs a newer loader than yours is left alone, since updating the loader is the fix.

New Fixes

  • Removed parameters: a method needs fewer inputs than before. Linkwright leaves out the extra ones.
  • Wrapped values: a value is now handed over inside a wrapper, such as a Supplier, Optional or Holder. Linkwright unwraps it.
  • Fields and getters: a field was swapped for a getter or setter method, or the other way around. Linkwright uses whichever one exists now.
  • Renamed getters: a method like getName() was renamed to name(), or back. Linkwright follows the new name.
  • Moved classes: a class moved to another package in the same mod. Linkwright points the mod at its new home.
  • Static changes: a method became static, or stopped being static. Linkwright adjusts the call to match.
  • Class and interface changes: a class became an interface, or the other way around. Linkwright adjusts the call to match.

New: Every Fix Is Tested First

  • Before the game is allowed to start, each fixed class is checked in memory with a bytecode verifier and then checked again from scratch.
  • If a fix would fail, it is not used, and you get the normal error instead of a crash.

Better Detection

  • Methods and fields that became private are now reported as problems. Before, they could pass the check and crash later.
  • Methods that changed between static and non-static are now caught and fixed when possible.

New Warnings

  • Wrong Java version: a mod built for a newer Java than the one your game runs on. You now get a clear message in the log and the report, instead of a confusing crash later.
  • Duplicate mods: the same mod in your mods folder twice, usually an old version left behind after an update.

Other Changes

  • The Forge 1.13.2 to 1.16.5 file now includes the part of ASM that Linkwright needs to test fixes, because Forge 1.13.2 and 1.14.4 don't load it.
  • Fabric users: the Java argument now uses the new file name, -javaagent:mods/linkwright-fabric-1.2.0.jar
