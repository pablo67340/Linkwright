Linkwright 1.3.0

New: Duplicate Mods Are Fixed Automatically

  • When the same mod is in your mods folder twice, usually an old version left behind after an update, Linkwright now keeps the copy you added last and disables the other one.
  • It goes by when each file was added, not by version number, so if you deliberately went back to an older version, that is the one it keeps.
  • The other copy is renamed to .jar.disabled, never deleted. Launchers like Prism and the CurseForge app show it as a disabled mod, so you can turn it back on with one click.
  • This happens before the loader reads your mods folder, so the game starts normally on the same launch. No restart needed.

Safe by Design

  • If Linkwright can't clearly tell which copy came last, it leaves both and tells you why. For example, when both copies were added at the same time, or on servers that don't record when files were added.
  • It never disables a copy that contains a mod the other copy doesn't have.
  • On NeoForge 21.9 and newer, the loader has already opened every mod before Linkwright starts, so Linkwright only warns there. NeoForge loads the highest version itself.

New Setting

  • disableDuplicates in config/linkwright.toml: set it to false to only get a warning instead.

Fabric Users

  • The Java argument uses the new file name: -javaagent:mods/linkwright-fabric-1.3.0.jar
